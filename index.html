How offsets are verified

Unique sentinel values are written through Roblox properties inside a sandboxed lab, then the live client memory is scanned. Every found address is re-sampled over time and classified:

LIVE — value tracks script phases STABLE — sentinel value in place DEAD — auto-filtered from releases
